# Криптоанализ классических шифров

Курсовой/исследовательский проект: автоматическое распознавание и криптоанализ
классических шифров (Цезарь, Атбаш, Полибий, Виженер) методами статистического
анализа — частотный анализ монограмм, индекс совпадения, метод Касиски, тест
Фридмана и биграммная модель языка. Программа получает на вход только шифртекст
(без указания шифра, языка или ключа) и восстанавливает открытый текст.

## Установка и запуск

Проект использует [uv](https://docs.astral.sh/uv/) для управления окружением
и зависимостями.

```bash
uv sync
```

Сгенерировать эталонные частотные таблицы из вложенных корпусов (уже
сгенерированы в `data/`, но шаг можно повторить после изменения корпусов):

```bash
uv run python -m cipherlab.build_frequency_data
```

Запустить тесты:

```bash
uv run pytest
```

Запустить веб-интерфейс:

```bash
uv run streamlit run app/streamlit_app.py
```

## Данные корпусов

Тексты в `data/raw_corpora/ru_sample.txt` и `en_sample.txt` — оригинальные
авторские тексты, написанные специально для этого проекта (не взяты из
конкретного стороннего произведения), чтобы избежать вопросов авторского права
и сетевых зависимостей при сборке. Они содержат связную прозу на бытовые,
исторические и природные темы, что даёт распределение букв, характерное для
естественной речи. `data/published_reference.json` содержит общепринятые
опубликованные частоты букв (стандартные таблицы, используемые в литературе по
криптоанализу) и служит для sanity-check тестов, а не источником для
статистики самого проекта.

## Ключевые формулы

- **Индекс совпадения**: `IC = Σ nᵢ(nᵢ-1) / (N(N-1))`.
  Опорные значения: EN текст ≈ 0.0667, случайный текст ≈ 1/26;
  RU текст ≈ 0.0553, случайный текст ≈ 1/32.
- **Хи-квадрат**: `χ² = Σ (Oᵢ-Eᵢ)²/Eᵢ` — оценка соответствия наблюдаемого
  текста эталонному распределению языка; меньше значение — лучше соответствие.
- **Метод Касиски**: поиск повторяющихся подстрок шифртекста, вычисление
  расстояний между повторами и их общих делителей — кандидаты длины ключа
  Виженера.
- **Тест Фридмана**: `L ≈ (IC_язык - IC_случайный) / (IC_наблюдаемый - IC_случайный)`,
  формула параметризована языком (работает и для русского, и для английского).
- **Биграммная оценка** (`stats.ngram`): средний логарифм правдоподобия пар
  соседних букв, `fitness = (1/(N-1)) Σ log P(bᵢbᵢ₊₁)`. Учитывает не только
  частоты букв, но и то, какие сочетания естественны для языка, поэтому надёжно
  распознаёт осмысленный текст на гораздо более коротких фрагментах, чем
  монограммный χ². Оценка нормирована на длину, что позволяет честно сравнивать
  расшифровки с ключами Виженера разной длины (длинный ключ не «переобучается»).

## Особенности реализации

- Буква "ё" в русском алфавите складывается в "е" при нормализации текста
  (стандартная практика для частотного анализа и решётки Полибия).
- Решётка Полибия: 5×5 для английского (I/J объединены), 6×6 для русского
  (32 рабочие буквы, 4 клетки решётки не используются).
- Распознавание языка ciphertext для Цезаря/Атбаша/Виженера выполняется по
  составу символов (кириллица/латиница), а не по частотному анализу — эти
  шифры не меняют алфавит текста, поэтому это надёжнее статистики.
- Пробелы, пунктуация и регистр букв сохраняются при шифровании/дешифровании
  (см. `cipherlab.format_preserving`) и в результате автовзлома — весь
  статистический анализ ведётся по нормализованному тексту, а формат
  восстанавливается уже поверх найденного шифра/ключа.
- **Автовзлом не «угадывает» шифр заранее.** Распознавание и взлом объединены:
  для каждого семейства (Цезарь, Атбаш, Виженер; Полибий — отдельно по составу
  из одних цифр) строится расшифровка, и все варианты сравниваются по одной
  объективной биграммной оценке (`stats.ngram`). Побеждает наиболее похожий на
  естественный язык результат. Это устраняет прежний класс ошибок, когда одна
  ошибка распознавания по IC приводила к полному провалу (Цезарь расшифровывался
  как Виженер и наоборот).
- Внутри взлома: **сдвиг Цезаря** подбирается по биграммной оценке всего текста;
  **столбцы Виженера** (буквы под одной буквой ключа, но не соседние в открытом
  тексте) решаются монограммным χ², так как их биграммы бессмысленны; **длина
  ключа** перебирается, а варианты сравниваются по нормированной биграммной
  оценке — при прочих равных предпочитается более короткий ключ (Оккам), поэтому
  ключ длины 1 корректно распознаётся как Цезарь. Модули Касиски и Фридмана
  сохранены как самостоятельные аналитические оценки длины ключа.
- **Уверенность результата.** Биграммная оценка переводится в уверенность
  [0, 1] через опорные значения, вычисленные из самой модели (энтропия
  распределения — «идеально похоже на язык», среднее по случайным парам —
  «шум»). Низкая уверенность честно сигнализирует, что расшифровка ненадёжна.
- На **коротких** шифртекстах есть фундаментальный предел статистики: Цезарь,
  Атбаш и Полибий взламываются надёжно от ~60–80 букв, Виженер — примерно от
  ~150 букв (нужно ~20–25 букв на каждую букву ключа). На более коротком вводе
  результат помечается низкой уверенностью, а не выдаётся за верный.
